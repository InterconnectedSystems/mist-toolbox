Authoring guide

Choose a tool's .js file. It is checked first, then written into this extension's tools/ folder and listed in tools/tools.json. The first install in a tab asks you to pick the mist-toolbox folder (the one you chose with Load unpacked). Have a Python or Node script instead? Use Copy AI prompt to convert it.
